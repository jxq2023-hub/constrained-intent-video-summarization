# Human evaluation protocol

## Design

Five adult raters evaluated anonymised key-frame summaries in two questionnaire volumes. Method order was blinded and varied by item. Each stimulus was identified by a neutral sample code; the private mapping used during collection is not part of this public package.

## Rating dimensions

Each dimension used a 1–5 Likert scale:

1. **Intent relevance** (`relevance_1_5`): how well the summary addresses the natural-language request.
2. **Both-concept coverage** (`both_concepts_coverage_1_5`): whether evidence for both requested concepts is present.
3. **Non-redundancy** (`non_redundancy_1_5`): whether selected frames add distinct information rather than repeating nearly identical content.
4. **Overall usefulness** (`overall_usefulness_1_5`): practical usefulness of the summary for the stated request.

Scale anchors: 1 = very poor / not satisfied; 2 = poor; 3 = acceptable; 4 = good; 5 = very good / fully satisfied.

## Public records

`human_ratings_long.csv` contains pseudonymous IDs (`R001`–`R005`), neutral stimulus codes, method labels used for analysis, scores, QFVS identifiers, and selected shot indices. It contains no names, e-mail addresses, student numbers, IP addresses, signed forms, or reversible identity table.

## Ethics boundary

Participants were informed about the task and voluntarily provided informed consent. Informed consent is not equivalent to approval or exemption by an ethics committee. No approval body, approval number, or exemption is asserted in this package because such documentation was not supplied.
